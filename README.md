# Library Admin System

A full-stack web application for managing library operations, including
students, seats, shifts, authentication, and monthly payments.

## Features
- Admin authentication
- Seat & shift management (4h / 8h / 12h)
- Student management
- Payment tracking
- Password reset via email

## Tech Stack
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express
- Database: MongoDB Atlas
- Auth: JWT
- Email: Nodemailer

## Deployment
- Frontend: Render
- Backend: Render
- Database: MongoDB Atlas

> This repository is private and intended for the library owner only.
